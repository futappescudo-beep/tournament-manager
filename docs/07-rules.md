# Reglas de cálculo y operación

Victoria = 3 puntos, empate = 1 y derrota = 0. Las posiciones se alimentan exclusivamente de partidos con estado `PLAYED`; el marcador se carga desde Resultados. Las zonas se seleccionan siguiendo el orden torneo → categoría → zona. La fase regular es una rueda por zona; los Play Off se definen manualmente y se juegan a partido único. Para el detalle de restricciones de jugadores e inscripciones, ver `02-business-rules.md`.
